# The Shadows of the Fog City

GitHub Pages upload package.

## Files
- `index.html` — main page
- `assets/ashcroft-seal.png` — wax seal image
- `assets/moonlit-phantom.mp3` — looping background music
- `.nojekyll` — prevents Jekyll processing

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and the `assets` folder **without changing the folder structure**.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

The music starts when the wax seal is clicked because browsers block unprompted audio autoplay. It loops continuously while the page remains open. Desktop browsers normally keep playing when the tab is in the background or the window is minimized; mobile operating systems may suspend background webpages.
